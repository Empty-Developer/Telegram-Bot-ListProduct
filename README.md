# Telegram Bot: «Product List Bot»

---
## Project goal

I created a bot for managing shopping 
lists in the Telegram messenger. The main goal 
of the project was to test my knowledge and skills 
in using the Python library: understanding its basic 
usage and working with the Telegram API.

### 1. Functionality (Commands)

The bot has a basic and full set of functions for working 
with the list

* **/start** - The command displays a welcome message and provides instructions on how to use the bot.
* **/help** - A command reference containing application commands and explanations of them.
* **/add {product}** - Adding a product occurs according to the following logic: the user enters a command, and then after a space, the product name is indicated.
* **/list** - Displays all products with numbers.
* **/done** - Deletes a product by the numbering specified by the user. Let's say he writes /done 3, then delete the product under number 3.
* **/clear** - Clears the entire list.
